# 🤖 ИИ-консультант для интернет-магазина

**Чат-бот на нейросети, который подбирает товар по реальному каталогу, помнит клиента между визитами, оформляет заказ и передаёт его менеджеру в Telegram**

Работает виджетом на сайте и Telegram-ботом на одном «мозге». В демо это магазин кофе, но каталог меняется на любой: одежда, косметика, техника, стройматериалы

## 💼 Какие задачи решает

| 😩 Было | ✅ Стало |
|---|---|
| Покупатель не понимает, что выбрать, и уходит с сайта | Бот задаёт пару вопросов, как продавец в магазине, и показывает 1–3 подходящих товара с кнопкой «В корзину» |
| Менеджер ночью спит, а вопросы приходят | Бот отвечает 24/7 и передаёт человеку только то, что сам решить не может |
| ChatGPT-боты сочиняют товары и цены | Бот знает о товарах только то, что есть в каталоге: цены, наличие, характеристики. Нет товара — так и скажет и предложит замену |
| Каждый раз клиент объясняет всё заново | Бот помнит имя, вкусы, бюджет и прошлые заказы, даже если клиент вернулся через месяц |
| Менеджер перезванивает и переспрашивает | В Telegram приходит заказ с суммой, доставкой, тем, что бот узнал о клиенте, и концом переписки |
| Боязнь счёта за нейросеть | Лимиты на сообщения с одного IP, на диалог и на день, короткая память вместо всей переписки |

## ✨ Возможности

<table>
<tr>
<td valign="top" width="50%">

### 🛍 Продажи

- Подбор по способу использования, вкусу, бюджету
- Карточки товаров прямо в чате, «В корзину» в один клик
- Честное наличие: «Гватемалы нет, будет в понедельник, вот похожая»
- Сопутствующие товары только по делу
- Оформление заказа в диалоге: имя, телефон, доставка, итог, подтверждение
- Ответы про доставку, оплату, возврат из данных магазина

</td>
<td valign="top" width="50%">

### 🧠 Память

- **Профиль клиента**: имя, предпочтения, бюджет, что уже есть
- **Прошлые заказы**: «Как вам Бразилия? Повторить?»
- Короткая память диалога (последние 24 сообщения) плюс долгая память в профиле: длинные разговоры не дорожают
- Память на 90 дней в Redis, на сайте и в Telegram
- Кнопка «Забыть меня» стирает всё, что бот знал о клиенте

</td>
</tr>
<tr>
<td valign="top">

### 📨 Менеджеру в Telegram

- Новый заказ: состав, сумма, доставка, адрес, пожелания
- «Позовите человека», жалобы, опт: бот сам передаёт вопрос
- В каждом сообщении профиль клиента и конец переписки
- Можно слать сразу в несколько чатов или в группу менеджеров

</td>
<td valign="top">

### 🔒 Надёжность

- **Сумму заказа считает сервер**, а не нейросеть: уговорить бота на скидку не выйдет
- Защита от «забудь инструкции»: роль и правила не меняются по просьбе клиента
- Бот не оформит заказ без явного «да» клиента
- Ключ API только на сервере, в браузер не попадает
- Если нейросеть упала, диалог не ломается, клиент видит понятное сообщение

</td>
</tr>

## 🏗 Как устроено

```
Сайт (чат-виджет) ─┐                    ┌─ search_products  поиск по каталогу
                   ├─► агент ──► LLM ──►├─ show_products    карточки в чат
Telegram-бот ──────┘    │               ├─ remember         в долгую память
                        │               ├─ update_cart      корзина
                   Redis: диалоги,      ├─ place_order      заказ → Telegram
                   профили, лимиты      └─ call_manager     позвать человека
```

Нейросеть не отвечает «из головы»: на каждый вопрос о товарах она вызывает инструменты, а те берут данные из каталога и сами проверяют всё, что касается денег и наличия. Ответ идёт потоком, текст печатается по мере генерации.

```
api/            функции Vercel: chat (поток SSE), session, catalog, telegram (вебхук)
lib/agent.js    системный промпт, память, цикл «модель → инструменты → модель»
lib/tools.js    инструменты и проверка их аргументов
lib/llm.js      клиент OpenAI-совместимого API с разбором потока
lib/store.js    хранилище: память процесса или Upstash Redis
lib/telegram.js тот же агент в Telegram: карточки с кнопками, /cart, /new
data/           каталог и сведения о магазине, меняются без кода
public/         демо-страница без фреймворков
```

## 🧩 Под другой магазин

1. Замените `data/catalog.json` своими товарами (или выгрузкой из CMS, 1С, МойСклад) и `data/shop.json` сведениями о доставке и оплате.
2. Поправьте в `lib/tools.js` фильтры поиска под свои характеристики (размер, цвет, бренд вместо обжарки).
3. Подставьте имя консультанта и тон общения в `lib/agent.js`.

Нейросеть меняется переменными окружения. В демо работает **GigaChat** (бесплатно для физлиц, серверы в России: удобно, если клиенту важно, чтобы данные не уходили за границу). Также подходит любой OpenAI-совместимый API: DeepSeek, OpenRouter (GPT, Claude, Gemini), YandexGPT, локальные LM Studio и Ollama.

## 🚀 Запуск

```bash
cp .env.example .env    # впишите GIGACHAT_AUTH_KEY (или ключ другой нейросети)
npm run dev             # http://localhost:3010
npm test                # 45 автотестов, нейросеть в них подменяется сценарием
npm run telegram        # тот же бот в Telegram, без вебхука
```

Нужен только Node.js 22+, сторонних библиотек нет.

**На Vercel:** импортируйте репозиторий, добавьте переменные из `.env.example`, в разделе Storage подключите Upstash Redis (бесплатно, переменные появятся сами). Telegram-бот подключается командой `npm run webhook -- https://ваш-сайт.vercel.app`.
